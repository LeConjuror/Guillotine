# Guillotine - File Carving Tool

Guillotine is a graphical user interface (GUI) tool designed to simplify the process of file carving on Linux systems. It is built on top of the Scalpel 2.02, providing an easy-to-use interface developed with Python and Tkinter.

## Features

- **GUI for Scalpel 2.02**: Leverages the robustness of Scalpel for file carving while providing an intuitive graphical interface.
- **Tooltip Assistance**: Integrated tooltips provided by TkTooltip.
- **Packaged for Linux**: Ready-to-use distribution packaged with PyInstaller for easy installation.

## Code
Main Source code is in guillotine.py

## Execution
Copy the folder in /dist, execute ./guillotine
